# 🚀 eidco Business OS

**نظام تشغيل وإدارة الأعمال السحابي المتكامل للشركات والأفراد.**

تطبيق ويب عصري مصمم لتبسيط العمليات التجارية اليومية، وإدارة المخزون، ومتابعة الحسابات والمعاملات المالية في مكان واحد، مع تجربة استخدام سريعة تدعم اللغة العربية بالكامل ومزامنة سحابية فورية.

## ✨ المميزات الرئيسية

* **📦 إدارة المخزون (Inventory Management):** تتبّع دقيق للأصناف والكميات وحركة المخزون لضمان استمرارية العمل وتجنب العجز أو الفائض.
* **💰 إدارة الحسابات والمعاملات التجارية:** تسجيل وتنظيم العمليات المالية، الفواتير، وحسابات العملاء والموردين بوضوح وسهولة.
* **☁️ مزامنة سحابية فورية (Real-Time Cloud Sync):** حفظ ومزامنة كافة بيانات المخزون والحسابات لحظياً لضمان الوصول الآمن إلى بيانات عملك في أي وقت ومن أي جهاز.
* **🌓 واجهة عصرية تدعم الوضع الليلي والنهاري (Dark / Light Mode):** تصميم متجاوب (`Responsive`) مبني ليدعم العربية (`RTL`) بسلاسة مع التبديل التلقائي واليدوي بين الثيم الفاتح والداكن.
* **🔐 الخصوصية وأمان البيانات:** بنية تقنية تراعي حماية الحسابات والبيانات التجارية وفق معايير أمان موثوقة.
